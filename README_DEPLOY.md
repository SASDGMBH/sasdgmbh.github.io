# SASD-GmbH GitHub Pages Website

This ZIP contains a first professional static website for `https://sasdgmbh.github.io`.

## Included pages

- `index.html` – landing page
- `services.html` – service overview
- `approach.html` – working method
- `public-work.html` – public GitHub positioning
- `contact.html` – contact page
- `assets/css/styles.css` – shared styling
- `assets/js/site.js` – mobile navigation
- `assets/img/*.svg` – original vector graphics

## Design direction

- calm B2B technology look
- dark navy / petrol color palette
- no stock photos
- original SVG graphics
- English main language for international GitHub visitors
- responsive static site suitable for GitHub Pages

## Deployment

1. Open the repository `SASDGMBH/sasdgmbh.github.io`.
2. Replace the current files with the content of this ZIP.
3. Commit and push:

```bash
git add .
git commit -m "Redesign SASD GitHub Pages website"
git push
```

4. Open `https://sasdgmbh.github.io` and check the result.

## Important production notes

Before using this as a final public company website, verify:

- official company address and location wording
- legal notice / Impressum
- privacy policy / Datenschutz
- correct contact email
- whether `https://www.sasd.de` should remain the main website or this GitHub Pages site should only be a technical profile page
- whether the page should be English-only, German-only or bilingual

The current version intentionally avoids detailed legal/company registry information because it must be verified before publication.
